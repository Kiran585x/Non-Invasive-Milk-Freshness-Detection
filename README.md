# 🥛 Non-Invasive Milk Freshness Detection System

## Project Overview

A research and development project focused on detecting milk freshness without opening the milk packet.

The project investigates UHF RFID sensing and capacitive sensing techniques to analyze changes associated with milk quality.

## Objectives
- Non-invasive milk freshness detection.
- UHF RFID-based sensing experiments.
- Capacitive sensing using FDC1004.
- Development of an embedded prototype.

## Hardware Components
- ESP32
- UHF RFID Reader MU922 / MU914
- FDC1004 Capacitance Sensor
- Copper Plate Electrodes
- Aluminum Foil Electrodes

## Technologies
- Embedded C/C++
- Arduino IDE
- UHF RFID
- Capacitive Sensing
- ESP32

## Experimental Work

1. UHF RFID-based experiments.
2. Parallel plate capacitance measurements.
3. Fresh and spoiled milk sample comparison.
4. Experimental data collection and analysis.
